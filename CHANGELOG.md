# Changelog

OnlyKonnect (local, browser-only edition). The online edition with accounts and cloud saves lives in
`onlykonnect_online` and is versioned separately from 2.0.0.

Versioning: bump `version` in `package.json` with each merge to `main`. The footer label reads it
from there.
- **Patch** (1.0.1): fixes and small tweaks
- **Minor** (1.1.0): new features
- **Major** (2.0.0): big changes, such as a new way of saving games

## 1.0.0 (2026-10-22)

First tracked release.

- Connections and Sequences rounds on six hieroglyph tiles, with text, image and audio clues
- Game Creator: puzzles, team names, guessing and steal times, first team per round, points per
  clue and steal, show/hide score tally, skip intro
- Host timer: Buzz, Correct/Wrong, automatic steals, Undo and Space/C/W shortcuts
- Team scores with a scoreboard (hidden by default)
- Mii-style avatars for the host and players, edited in the Game Creator
- 3D opening titles followed by host and team introductions
- Light 3D theme across the app; one sound control with live volume
- Game board fits any screen size without tiles covering the team cards
